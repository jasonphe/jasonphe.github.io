# Voice recording scripts

One take per game: read the lines top to bottom, with about a second of silence between lines.
Keep pauses inside a line short, so the split doesn't land there. If you flub one, pause and say
it again, and note which line it was. Any format works (M4A from the phone is fine).

Lines you've already recorded are left out, and Fetch! is done. That leaves 162 lines.
